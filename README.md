# 扫码点餐小程序

基于 uni-app、Vue 2 和 uniCloud 的扫码堂食 / 外卖点餐项目，包含微信小程序用户端和 uni-admin 管理后台。两端需绑定同一 uniCloud 服务空间。

## 目录

```text
点餐小程序的用户端/    微信小程序
点餐小程序的后台端/    管理后台（H5 /admin/）
tests/                本地回归脚本
```

HBuilderX 分别导入两个子目录，不要把仓库根目录当作单个 uni-app 项目运行。
